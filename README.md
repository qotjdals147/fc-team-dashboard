# fv6 프로젝트 폴더

## 루트 (FC 제로 운영 — GitHub Pages)

| 파일 | 용도 |
|------|------|
| `index.html` `app.js` `api.js` `style.css` `data.js` | FC 제로 클럽 사이트 (배포 루트) |

## 하위 폴더

| 폴더 | 내용 |
|------|------|
| **`docs/`** | 프로젝트 문서 (`HANDOFF.md`, `BUSINESS_VISION.md` 등) |
| **`docs/legacy/`** | 구 스냅샷 (`SUPABASE_GUIDE.txt`) |
| **`manual/`** | 업무 매뉴얼 HTML (FC 제로와 별개) |
| **`setup/`** | Supabase SQL·배포 가이드 |
| **`platform/`** | 사업 플랫폼 (FC 제로와 별도) |
| **`portfolio/`** | 포트폴리오 HTML·슬라이드 |
| **`portfolio-assets/`** | 포트폴리오 캡처 이미지 |
| **`projects/`** | 기타 프로젝트 (`MERANTOOL(ADS)` 등) |
| **`archive/`** | 구버전 zip·추출본 |
| **`links/`** | 바로가기 `.url` |
| **`scripts/`** | 유틸 Python 스크립트 |

## 업무 매뉴얼 열기

- `manual/업무매뉴얼_로컬서버.bat` — 로컬 HTTP 서버
- `Downloads/업무매뉴얼_브라우저로열기.bat` — Chrome 직접 열기
